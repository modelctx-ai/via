usage: via acme thing:do --title <str> --filter <json> --pages <json>
         --point <json> --due <str> [--legacy-tuple <json>] [--count <num>]
         [--draft]

Do the thing
  --title           <str>
  --filter          <json>
  --filter.state    open|closed · required
  --filter.labels   str[]
  --filter.range    json · required
  --pages           JSON array of objects with keys:
    title           str · required
    children        json · required
  --point           repeat the flag or pass a JSON array
  --due             <str>
  --legacy-tuple    repeat the flag or pass a JSON array
  --draft           default: false
accepts extra fields: --<name> <value>
example: via acme thing:do --title text --filter.state open --filter.range.from 2026-01-15 --pages '[{"title":"text","children":[]}]' --point '[1,1]' --due 2026-01-15T09:00:00Z
alias: thing_do
